Os agentes do Piggy, cada um com uma função no produto. Arte oficial de `frontend/brand/agents/`.

- `agente-xerife`, `agente-carteiro`, `agente-detetive`: versões de avatar (menores); os mesmos três também em versão hero (`-hero`).
- `agente-cofre`, `agente-faria_limer`, `agente-reporter`, `agente-barao`, `agente-aviador`: versões "hero" (maiores, para composição de landing).

Podem participar da narrativa de marketing e do chat. Os números do dashboard leem primeiro: arte não compete com eles.
