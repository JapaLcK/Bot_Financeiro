Piggy, o mascote. Arte oficial; use só estas.

- `mascot.webp`: Piggy de frente, rosa, pose padrão.
- `piggy-3d.png`: render 3D com transparência (1254×1254), aprovado para a tela de boas-vindas do app: rosa vivo, óculos pretos, moletom preto, cordões verde-limão.

Piggy é **masculino** ("pro Piggy"). O produto o usa na boas-vindas e no chat; no dashboard os números leem primeiro e a arte não compete com eles.
