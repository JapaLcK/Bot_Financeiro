Barra empilhada de 10px que mostra a proporção de cada parte, de `app/src/ui/componentes/BarraComposicao.tsx`.

**Quem fornece:** `segments` (`[{value, color}]`), com cores de dado (`--cat-*`, `--serie-*`).

É decorativa (escondida do leitor de tela): o nome e o valor de cada parte têm de estar escritos ao lado. Cada segmento tem no mínimo 4px e 2px de folga entre eles.
