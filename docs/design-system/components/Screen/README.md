Fundo de tela: `bg` com 16px de margem lateral, de `app/src/ui/componentes/Screen.tsx`.

**Quem fornece:** o conteúdo da tela.

No app, `Screen` também soma as áreas seguras do aparelho, rola o conteúdo, sobe o campo focado acima do teclado e oferece puxar para atualizar. Na web só o fundo e a margem se aplicam. As telas de acesso (login) usam margem de 20px.
