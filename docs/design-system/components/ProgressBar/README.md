Barra de 8px com `radius-bar`, trilho em `border`, de `app/src/ui/componentes/ProgressBar.tsx`.

**Quem fornece:** `value` de 0 a 1, e `tone` (`brand`, `positive`, `warning`, `danger`) ou `color` com um matiz de dado (`--cat-*`, `--serie-*`).

O preenchimento no rosa sobre o trilho claro tem só 2,9:1, então **escreva sempre a porcentagem ou o valor ao lado**. `positive` é meta batida; `warning`, gasto acima do ritmo; `danger`, estouro.
