Conteúdo de uma folha que sobe de baixo: `bg` com 20px em cima e 16px nas laterais e embaixo, de `app/src/ui/componentes/Sheet.tsx`.

**Quem fornece:** o conteúdo da folha.

No app a folha é a nativa do iOS (`formSheet`) com alça visível e duas paradas, metade da tela e tela cheia. Alça, cantos e sombra vêm do sistema, não dos tokens. Use para criar ou editar uma coisa só ("Novo gasto").
