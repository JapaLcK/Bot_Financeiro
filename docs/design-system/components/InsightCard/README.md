Card elevado com um sticker do Piggy, título, mensagem e uma ação opcional, de `app/src/ui/componentes/InsightCard.tsx`.

**Quem fornece:** `title`, `message`, e opcionalmente `sticker` (URL de um sticker oficial, 40px) e `action` (`{label, onClick}`, vira botão `ghost`).

Use para um achado do Piggy sobre o mês ("Delivery subiu 18%"). Uma ideia por card; o número vai no texto, não só na cor.
