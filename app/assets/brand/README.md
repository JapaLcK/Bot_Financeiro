# Piggy 3D

`piggy-3d.png` é o render com transparência aprovado para a boas-vindas.
Gerado com a ferramenta nativa image_gen a partir dos stickers locais
`hello.webp` e `point.webp`: rosa vivo, óculos pretos, moletom preto,
cordões verde-limão e braços cruzados. A imagem é empacotada pelo Metro;
nenhuma geração de imagem ou chamada de rede acontece no aplicativo.
