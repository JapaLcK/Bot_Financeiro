# Assinatura de e-mail PigBank

Arquivos:

- `assinatura-pigbank.html`: versão visual pronta para copiar no Gmail ou Outlook.
- `assinatura-texto.txt`: alternativa em texto simples.
- `pigbank-mascote-email.png`: imagem otimizada para e-mail (276 × 320 px, fundo transparente).
- `pigbank-mascote-original.png`: imagem original em alta resolução.
- `preview-assinatura.png`: prévia renderizada da composição.

## Personalização

Antes de usar, substitua em `assinatura-pigbank.html` e `assinatura-texto.txt`:

- `SEU NOME`
- `Seu cargo`
- `seu.nome@pigbankai.com`
- `+55 (00) 00000-0000`
- `+5500000000000` no link `tel:`

## Como instalar

1. Abra `assinatura-pigbank.html` no navegador.
2. Selecione somente a assinatura visual e copie.
3. Cole no editor de assinatura do Gmail ou Outlook.
4. Caso a imagem não seja incorporada automaticamente, insira manualmente `pigbank-mascote-email.png` no mesmo local.
5. Envie um e-mail de teste para conferir a assinatura no computador e no celular.

O HTML usa tabela e estilos inline para maior compatibilidade entre clientes de e-mail.
